# 數學英雄傳 v2：南一版題庫與分析後台

辰光國小「數學英雄傳」的題庫和程式。單元目錄依南一版國小數學 1上～6下。

- 共 111 個單元，1,110 題。
- 每單元 10 題：5 題選擇、3 題填充、2 題應用。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 線上瀏覽與列印題庫：https://cyysongyy.github.io/young-app-library/math-bank/ |
| `questions.json` | 給 Apps Script 匯入用，格式和試算表欄位相同 |
| `南一數學題庫_115.xlsx` | 12 個分頁（1上～6下），可直接複製貼到試算表 |
| `data/g1～g6.json` | 題目原稿，要修改題目請改這裡 |
| `gas/Code.gs` | 後端程式 |
| `gas/Index.html` | 學生作答頁 |
| `gas/Admin.html` | 教師分析後台 |

## 安裝步驟

1. 開啟試算表「南一數學測驗成績單」，點「擴充功能 → Apps Script」。
2. 用 `gas/` 裡的三個檔案，取代或新增 `Code.gs`、`Index`、`Admin`。HTML 檔名不要加 .html。
3. 修改 `Code.gs` 第 9 行 `ADMIN_PASSWORD`，換成自己的後台密碼。
4. 在編輯器上方選擇 `importBank` 函式，按「執行」。第一次執行需要授權。執行後：
   - 12 個年級分頁會換成新題庫。
   - 舊題目會自動備份成隱藏分頁，名稱含「_備份」。
5. 點「部署 → 管理部署作業」，編輯原本的部署，版本選「新版本」，再按部署。這樣學生用的網址不會變。

部署完成後：

- 學生網址不變。
- 教師後台：學生網址後面加上 `?page=admin`。

## 這一版改了什麼

**學生端**

- 選擇題改成點選按鈕，不用打字。
- 填充題會顯示作答格式提示。
- 判分更寬容：全形或半形、多打空格、單位寫不寫、等值分數都算對。例如 4 又 2/4 也算對。
- 未作答的題目會先提醒，再按一次才交卷。
- 每個單元會記住自己的最佳分數。
- 交卷後可以「只練習答錯的題目」。練習不計分，也不寫入紀錄。

**後端**

- 判分移到伺服器端。學生的瀏覽器拿不到答案。
- 每一題的作答都寫入新分頁「Log_作答明細」。

**教師後台**

可依年級、班級、期間篩選，內容包括：

- 各班平均分數
- 分數分布
- 各單元平均分數，低於 60 分會標示 ⚠️
- 題型答對率
- 每日測驗次數與每日平均分數
- 最常答錯的題目，並列出最常見的錯誤答案
- 需要關注的學生
- 全部學生成績，可匯出 CSV
