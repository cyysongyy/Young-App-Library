# 數學英雄傳 v3：線上作答、立即回饋、迷思概念分析

辰光國小「數學英雄傳」的題庫與程式。單元目錄依南一版國小數學 1上～6下：

- 共 111 個單元、1,110 題。
- 每單元 10 題：5 題選擇、3 題填充、2 題應用。
- 每一題都標註「概念」，每個錯誤選項或常見錯答也都對應到具體的「迷思概念」。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 線上瀏覽與列印題庫（含概念、迷思）：https://cyysongyy.github.io/Young-App-Library/math-bank/ |
| `questions.json` | 給 Apps Script 匯入用，共 9 欄，和試算表欄位相同 |
| `南一數學題庫_115.xlsx` | 12 個分頁（1上～6下），也可以手動貼到試算表 |
| `data/g1～g6.json` | 題目原稿 |
| `data/tags_g1～g6.json` | 每題的概念與迷思對照 |
| `gas/Code.gs` | 後端程式 |
| `gas/Index.html` | 學生作答頁 |
| `gas/Admin.html` | 教師分析後台 |

## 安裝步驟

1. 開啟試算表「南一數學測驗成績單」，點「擴充功能 → Apps Script」。
2. 用 `gas/` 裡的三個檔案，取代或新增 `Code.gs`、`Index`、`Admin`。HTML 檔名不要加 .html。
3. 修改 `Code.gs` 的 `ADMIN_PASSWORD`，換成自己的後台密碼。
4. 在編輯器上方選 `importBank`，按「執行」。第一次執行需要授權。執行後會：
   - 把題庫換成新版。舊題目會備份成隱藏分頁。
   - 建立「學生名單」分頁。
5. 在「學生名單」分頁填入 **班級、座號、姓名**，例如 `三甲｜5｜王小明`。
6. 點「部署 → 管理部署作業 → 編輯 → 新版本 → 部署」。學生用的網址不會變。

部署完成後：

- 教師後台：學生網址後面加上 `?page=admin`。
- 學生專屬登入：網址後面加上 `?c=三甲&s=5`。後台的「登入 QR 卡」可以整班一次列印。

## 學生端

- **登入**：點班級，再點座號，姓名會自動帶出。也可以掃自己的 QR 卡，直接選好。
- **作答**：一次一題，按「確認答案」後立刻顯示：
  - 對或錯、正確答案、解析。
  - 答錯時提示可能的迷思，例如「進位忘記加 1」。
- **判分**：全形或半形、多打空格、單位寫不寫、等值分數都算對。題目要求「最簡分數」時，未約分不算對。
- **結算**：顯示分數並自動上傳。可以「再練一次答錯的題目」，練習不計分。

## 教師後台

| 分頁 | 內容 |
|---|---|
| 總覽 | 登入次數、測驗次數、平均分數；各班、各單元、題型、每日趨勢；最常答錯的題目和主要迷思 |
| 🧠 迷思概念 | 出現最多學生的迷思排行、答對率最低的概念、迷思總表（可展開學生名單） |
| 👩‍🎓 學生 | 需要關注的學生；點姓名可看個人的測驗紀錄、登入時間、迷思次數 |
| 🕒 登入紀錄 | 每次登入的日期時間，以及那次登入完成的測驗與分數 |
| 📱 登入 QR 卡 | 依「學生名單」產生每位學生的登入 QR，可直接列印 |

所有分頁都可以依年級、班級、期間篩選。學生成績可以匯出 CSV。
